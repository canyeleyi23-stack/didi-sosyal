DİDİ SOSYAL — RENDER KURULUMU

GitHub'a bu ZIP içindeki tüm dosyaları yükleyin.

Render ayarları:
Language: Node
Root Directory: boş
Build Command: npm install
Start Command: npm start
Health Check Path: /api/health

Environment:
NODE_ENV=production
SESSION_SECRET=Render içinden Generate kullanın

ÖNEMLİ:
- Yeni Web Service oluştururken Docker değil Node seçin.
- Start Command alanına node src/server.js yazmayın.
- Doğru başlangıç dosyası: src/server.js
- package.json içindeki npm start komutu otomatik olarak doğru dosyayı başlatır.
