DİDİ SOSYAL PRO 8.0 — AYNI TASARIM

Bu paket, gönderdiğiniz HTML tasarımını korur.

AKTİF ÖZELLİKLER
- Aynı logo, üst menü, sol menü, hikâyeler, akış ve sağ panel
- Açık/koyu tema
- Fotoğraf, video ve YouTube paylaşımı
- 5 dakika video sınırı
- Gönderi düzenleme/silme
- Beğeni, yorum, kaydetme ve paylaşma
- Profil düzenleme
- Arama
- Mobil uyumluluk
- Profil ve gönderilerin sunucu tarafında JSON dosyasına kalıcı kaydı
- Render PORT desteği

YEREL KURULUM
1. npm install
2. npm start
3. http://localhost:3001
